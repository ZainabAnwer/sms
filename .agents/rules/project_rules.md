# Project Memory & Operating Rules

1. **State File Auto-Update:**
   - Update `03_CURRENT_STATUS_AND_PROTOTYPE_AUDIT.md` after every prompt/task with recent progress and current status.
2. **No Git Push Without Explicit Permission:**
   - Never push or commit to GitHub unless explicitly told by the user.
3. **Understand First Before Implementing:**
   - On every request, explicitly explain understanding of the requirement first before executing code changes.
